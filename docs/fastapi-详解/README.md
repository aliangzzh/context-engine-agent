| 文档 | 是什么 | 什么时候看 |
|---|---|---|
| `真实代码从0到1带练.md` | 用项目真实 `main.py` 走 8 步，每步：代码位置 + 命令 + 真实输出 | **首选**，想理解这 197 行怎么来的 |
| `从0到1一步步跑通.md` | 8 个渐进文件，每步起服务打探针 | 想看"接口从 404 变 200"的过程 |

## 这些文档里"你暂时不用管"的内容

以下都是**工程细节**，不是 FastAPI 知识点。提前看记不住，遇到问题再看：

| 内容 | 出现在 | 什么时候才需要 |
|---|---|---|
| `/docs` 白页、CDN、vendor swagger-ui | `真实代码跑通检测.md` | 要在**无外网环境部署**时 |
| 静态页面挂载（`FileResponse`/`StaticFiles`） | 同上的第六节 | 想让 FastAPI 也直接提供界面时 |
| stdlib 入口 vs FastAPI 入口的差异 | 多份 | 理解这个项目的"离线优先"设计时 |
| 404 格式漏网、双重校验 | `真实代码跑通检测.md` | 代码评审被挑出来时 |
| SSE 生成器 + 线程池没生效 | 多份 | 换成真实模型 API、并发上来以后 |
| Vue3 三个页面、`npm install` | 多份 | 那是前端的事，与你现在无关 |
